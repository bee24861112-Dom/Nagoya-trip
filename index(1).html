每日行程

DAY 01　/　11/21（六）抵達名古屋、常滑招財貓
  1. 07:05星宇 JX320 自臺中 T2 起飛
  2. 10:40JX320 抵達中部國際機場 T1
  3. 11:30搭名鐵前往常滑站
  4. 12:00巨大招財貓、招財貓大道
  5. 12:45指定席特急至金山，轉車前往久屋大通
  6. 15:00住宿入住、休息
  7. 18:30晚餐 · 矢場とん 矢場町本店

名鐵指定席需備妥基本車票與 μ-ticket。

DAY 02　/　11/22（日）熱田神宮、名古屋港水族館
  1. 08:20久屋大通 → 熱田神宮西
  2. 09:00熱田神宮參拜
  3. 10:15蓬萊軒神宮店登記候位
  4. 11:30午餐 · 蓬萊軒鰻魚飯
  5. 12:40傳馬町 → 金山 → 名古屋港
  6. 13:25名古屋港水族館
  7. 17:30返回久屋大通

若蓬萊軒沒排到第一輪，依入店時間調整水族館行程。

DAY 03　/　11/23（一）高山、白川鄉一日遊
  1. 07:10搭櫻通線前往名古屋站
  2. 07:50VIP LINER 集合，08:00 出發
  3. 10:30高山老街自由活動 90 分鐘
  4. 12:45白川鄉合掌村，停留 150 分鐘
  5. 午餐IRORI 優先，排隊超過 20 分鐘就換店
  6. 15:15集合上車
  7. 18:00預計返回名古屋站

日本國定假日，回程可能因塞車延後。

DAY 04　/　11/24（二）名古屋城、壽喜燒與夜景
  1. 06:25久屋大通 → 國際中心
  2. 06:45KAKO 花車本店排隊
  3. 07:00早餐 · KAKO 小倉吐司
  4. 09:00名古屋城、本丸御殿
  5. 12:00午餐 · 馬喰一代 WEST 壽喜燒
  6. 14:00四間道、圓頓寺商店街
  7. 16:00名古屋站周邊購物
  8. 18:00Sky Promenade 看夜景

雨天備案：改在名古屋站吃晚餐。

DAY 05　/　11/25（三）吉卜力公園
  1. 06:45東山線 → 藤丘 → Linimo
  2. 08:00抵達園區，排魔女之谷
  3. 10:00魔女之谷，優先購買茵茵娃娃
  4. 11:30 前後園區午餐，依排隊情況調整
  5. 14:00吉卜力大倉庫｜固定入場
  6. 15:30青春之丘、魔法公主之里
  7. 最後龍貓之森
  8. 17:00Linimo → 藤丘 → 榮

優先排茵茵娃娃，記得預留走到大倉庫的時間。

DAY 06　/　11/26（四）大須、榮商圈與飛驒牛
  1. 08:40久屋大通 → 大須觀音
  2. 09:00大須觀音參拜
  3. 09:30大須商店街散步
  4. 10:10三輪神社
  5. 11:30午餐 · 伏見屋本店飛驒牛燒肉
  6. 13:20榮商圈購物 · PARCO、松坂屋
  7. 16:30大須商店街購物
  8. 18:30 後晚餐自由安排

手帳列的午餐時段為 11:30–14:30。買得多可以先回住宿處寄放。

DAY 07　/　11/27（五）回程
  1. 10:00住宿退房
  2. 11:10久屋大通 → 金山 → 中部國際機場
  3. 12:30抵達 T1，確認退稅事項、報到與托運
  4. 13:30安檢、出境審查
  5. 14:10免稅店購物、簡單用餐
  6. 15:10前往登機門
  7. 16:10JX1321 起飛
  8. 18:30抵達臺中國際機場 T2

手帳預留至少 3.5 小時辦理機場手續。
